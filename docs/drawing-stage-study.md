# 多级原理图研究与验收 · 2026-11-06

本轮把多级、差分和闭环电路中的布局经验写入 [绘图指导](drawing-guide.md)、[典型结构](drawing-patterns.md)和[验收规则](drawing-acceptance.md)。公开源码包含规则和合成测试，不包含第三方图纸副本。

- [TI SLOA049D](https://www.ti.com/lit/an/sloa049b/sloa049b.pdf) 图 B-1/B-2：对齐真实的级间端口；每级保留自己的 RC 和反馈。Sallen-Key 的外部滤波回路与局部增益反馈分开，MFB 保留两条反馈。
- [TI SLOA060](https://www.ti.com/lit/an/sloa060/sloa060.pdf) 图 16、18：振荡主路可以回折，按实际信号路径保留闭环及各级跟随反馈。
- [TI SBOA281](https://www.ti.com/lit/an/sboa281/sboa281.pdf) 与 [SBOA282](https://www.ti.com/lit/an/sboa282/sboa282.pdf)：仪放的成对支路、跨级增益网络与差分级需要保留。共享供电不决定级间排序。
- ADI LT1994 数据手册第 1 页：反馈在串联电阻前取样，串联电阻后的差分电容属于另一段；布局调整不能更改取点。Qucs-S 和 KiCad 原理图资料也用于复核分块和网标规则。

当前自动布局仅在真实引脚、输入输出、前向顺序和局部反馈都明确时识别单链。跨级反馈、并联级、混接供电和归属不清的结构走保守回退。合成回归覆盖旋转和镜像、反馈归属、网络等价和探针保留。历史研究另外比较了水平、旋转 90° 和跟随器三种图例，并在独立编辑器中检查应用与撤销；复杂结构仍需按图人工验收。
