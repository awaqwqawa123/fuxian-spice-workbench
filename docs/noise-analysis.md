# 噪声分析

在“仿真设置”选择“噪声分析”，设置起始/终止频率、每十倍频程采样点、参考电压源和参考输出节点。频率设置沿用 AC 参数；不同分析配置可以分别保存不同频段。参考电压源的 AC 幅度须大于零。输出相对 GND；差分输出和电流输入源可在手工网表中指定。

曲线分别为输出噪声 `onoise_spectrum` 和输入等效噪声 `inoise_spectrum`，单位为 V/√Hz。参考输入为独立电流源时，输入密度单位为 A/√Hz。图形入口按对数频率绘图，手工入口的 lin 扫描使用线性频率轴；均可查看原始采样。图形入口支持 CSV 和最终测试报告，密度与积分 RMS 总量分别标注。

手工网表接受单个 `.noise V(输出[,参考节点]) 输入源 dec|oct|lin 点数 起始频率 终止频率 [汇总间隔]`，也接受 `.control` 内的 `noise` 命令。输入源为独立 V/I 源。SPICE 数值中 `M` 为毫，`Meg` 为兆。示例：

```spice
RC thermal noise
V1 vin 0 DC 0 AC 1
R1 vin vout 1k
C1 vout 0 100n
.noise V(vout) V1 dec 100 10 100k
.end
```

噪声分析需要同时保存谱密度与积分向量。此分析的 `.save` 统一执行为 `.save all`，编辑器会说明并显示实际执行网表；手工草稿保持原文。普通 AC/TRAN/DC/OP 分析保留原有保存规则。

结果来自 ngspice 的噪声模型。理想运放和教学行为模型可能不包含真实器件的噪声，不能据此认定实物没有噪声。普通电压/电流探针不作为噪声曲线；噪声视图只显示本次所选输出及输入等效噪声。LTspice ASC 导出保留 `.noise`，现有受限 ASC/电路文本导入器仍不支持导入噪声分析，可通过手工网表运行。

ngspice 会生成频谱和积分两个独立结果，程序明确导出频谱，并从求解器读取该频段的 RMS 总量。未取得积分值时显示缺失状态，不以末端谱密度冒充总量。`eecircuit-engine` 1.8 没有公开的命令配置接口，读取积分值的适配封装在 `noise-simulation.ts`；其命令协议有运行时检查，升级引擎时需重新验证。

验证覆盖真实生产 Worker 的电阻热噪声 `sqrt(4 k T R)`、RC 滤波噪声谱和频段积分，及界面设置→真实求解→绘图/配置恢复/报告、手工网表、助手摘要与持久会话。噪声谱不填入普通节点电压、电源电流或增益数组。
