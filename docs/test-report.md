# 电路设计与仿真验证报告

最终测试报告用于整理设计说明、技术文档和仿真验证记录。报告以当前电路及所有当前配置的有效结果为依据，支持预览、自包含 HTML、PDF 打印、可编辑 Word、Markdown 和完整归档包。

## 生成步骤

1. 完成电路连接、器件参数、模型和测量探针配置。
2. 建立需要的仿真配置，并逐项运行。可按设计需求组合交流、瞬态、直流、工作点或噪声分析。
3. 打开“最终测试报告”，检查测试进度表。所有配置均须显示“已完成”；“未运行”“需重跑”“结果无效”会阻止最终报告导出。
4. 填写文档编号、报告版本、工程版本、编写与审核人员，以及设计目的、原理、要求和结论备注。
5. 为各测试填写目的和工况，按需要设置测量窗口、稳态声明、阶跃测量初值与目标、容差带和保持时间，或 AC 参考频率。
6. 在指标验收中选择配置、测量对象和指标，设置上下限，或目标值与绝对容差。验收数值使用报告显示的基本单位，例如 V、A、s、Hz、dB；`1 ms` 应填写 `0.001` 秒。
7. 规划电源、负载、温度、容差等验证边界，将声明覆盖的要求绑定到有效配置；不适用条目填写理由。
8. 核对正式报告预览中的测量方法、窗口、警告、指标验收和覆盖状态，然后导出。

报告信息、测试说明、后处理设置、验收规则和覆盖要求保存到工程的 `report` 配置，随工程保存与恢复。它们不改变电气仿真参数；修改电路或仿真配置后，相关运行仍须重新执行。最近导出记录只记录版本、时间、格式、结论和运行 ID，不是历史报告与工程的完整快照；需要历史复现时保存对应归档包。

## 报告内容

正式报告包括封面与文档控制、目录、设计目标、电路与模型、功能模块和理论依据、测试方法及可复现条件、各项运行的测量和分析、专业指标、带编号的图表、指标验收、测试覆盖、综合结论及网表日志附录。图表保留配置名称、窗口、单位和证据。设置窗口后，波形标示选取区间；具备测量标记的指标提供局部图和关键点表。

自动内容依据真实电路连接、模型和仿真结果生成。能够明确识别的 RC / RLC 网络提供公式、理论参数和假设；复杂自定义电路不凭器件名称推断整体功能。用户设计说明、工况和覆盖声明会明确标注，编写与审核人员需核实模块、反馈、偏置、保护及选型依据。

温度、初始条件和求解器选项来自实际网表中的 `.temp`、`.ic`、`.nodeset`、`.options` 指令。未显式指定时，报告明确使用求解器默认设置，不填入推测值。完整模型与网表用于复现；人工工况说明不等于实际执行了温度或容差扫描。

## 专业测量与自动验收

| 测试 | 可用指标与条件 |
| --- | --- |
| 工作点 / DC | 最小、最大、末次值；具备真实端压与有方向求解器支流时计算吸收功率。 |
| 瞬态 | 窗口最小、最大、峰峰值、末值、时间加权平均、RMS；明确阶跃定义时计算上升 / 下降时间、过冲和保持至窗口末端的稳定时间。 |
| AC | 扫描内幅值峰值、峰值处相位；明确参考频率后计算相对参考值下降 3 dB 的上下截止和带宽。输出传递增益与探针绝对幅值分别注明。 |
| 噪声 | 噪声密度极值；全扫描积分 RMS 总量仅引用求解器返回值，不能直接把幅度谱密度相加。 |

瞬态统计按真实自适应时间坐标分段积分，窗口边界在相邻点间插值。未声明窗口时包含启动过程。稳态声明由用户提供，需要检查波形确已稳定；末值不代表自动进入稳态。阶跃测量使用明确初值和目标，错误方向、未到阈值或观察时长不足会标为“无法评价”。稳定时间只证明所观察区间内持续满足容差。

AC 截止必须在扫描内观察到有效、唯一的交叉，不把扫描边界当作截止。RC 理论对照在可识别完整拓扑、明确参考频率和相同测量定义时生成；区分极点处的 −3.0103 dB 和相对参考增益的 −3.000 dB。多工况表只汇集同信号、同量纲、同定义和同测量窗口的指标，工况意义仍由工程师审核。

温度、器件参数扫描会逐个展开实际工况。该配置的窗口及数值规则应用到每个扫描点；任何一个扫描点不满足即显示“存在不满足指标”。每个扫描点分别列出实际器件参数、网表、测量和验收证据；RC 理论对比按各点的真实元件参数计算，不使用起始电路参数代替整组扫描。缺少扫描点或扫描设置已改变时阻止导出。

效率、相位裕度、增益裕度等需要明确功率边界或真正的环路测量证据；现有数据不足时列为“无法评价”，不能用普通输出波形推断。数值验收约束缺少数据或方法不适用也会明确标注。

## 完整归档内容

ZIP 内含自包含 HTML、Markdown、生成时报告快照、工程、仿真配置及完整结果；`runs/` 逐项保存实际运行工程、结果、CSV、网表和求解器日志，参数扫描每个点单独保存。工程内模型定义、来源、端口及元数据随各项运行保存；内置模型及实际使用的行为定义以网表为准。

CSV 是解析后的求解器数据，不是求解器原生 `.raw` 文件。AC 同时保留复数实部、虚部、传递增益和相位，噪声密度与积分 RMS 总量分开保存。`manifest.json` 提供运行 ID、文件长度及 CRC32 完整性校验；CRC32 不作为数字签名。复现还应使用相同求解器版本并核对实际模型与运行指令。

## 导出格式

| 操作 | 适用场景 |
| --- | --- |
| 生成最终测试文档 | 下载自包含 HTML，便于浏览、归档和分享，也可离线打开后打印。 |
| 打印 / 保存 PDF | 打开浏览器打印窗口，选择“另存为 PDF”或系统 PDF 打印机，生成 A4 文档。 |
| 导出 Word | 下载真正的 `.docx` 文档，可在 Word、WPS 等软件中继续编写和排版；浏览器导出包含报告图像。 |
| 导出 Markdown | 下载 `.md`，便于纳入项目文档、版本管理或其他文档编写工具。 |
| 导出完整归档 | 将报告、工程、配置、原始结果、模型、实际网表和日志打包，用于复现与交付。 |

预览与导出使用同一份报告内容。若浏览器无法打开打印窗口，可下载 HTML 后用浏览器打开，再打印或保存为 PDF。

HTML 自包含原理图和波形 SVG，不需联网。Word 同时内嵌 PNG 图像及 SVG，正文和表格可编辑。Markdown 图表使用内嵌 SVG 数据图片，部分 Markdown 平台会屏蔽此格式；在这些平台查看完整图表请使用 HTML、Word 或 PDF。

Word 带章节导航、可更新目录、页码与总页数。打开后按 Word / WPS 提示更新域，或在目录处选择“更新域 / 更新目录”，以获得当前版式的目录页码。HTML / PDF 提供报告目录，打印页码由兼容浏览器的分页样式生成；旧浏览器可在打印设置中打开页眉页脚。

瞬态平均值及 RMS 在实际采样时间窗口内按相邻点线性插值积分，兼容自适应步长；包含启动过程，不自动视为稳态指标。AC 探针幅值以 1 V 或 1 A 为参考，区别于参考输出与输入之比的传递增益。噪声谱密度与积分 RMS 噪声分别标明，积分总量仅引用求解器返回值。

## 结果有效性与结论

修改电路的连接、参数、器件模型或仿真条件后，相关配置的旧结果会标记为“需重跑”。仅调整电路布局、不改变电气关系时，可继续使用对应结果。报告不会用旧结果替代当前配置的验证。

增加、删除或改变探针测量端点与方向后也需要重新运行；仅移动探针标牌不影响报告结果。

“已完成”表示有效运行。仅在文字说明中填写阈值不自动执行验收；需在数值验收规则中指定配置、信号、指标和限制。报告结论为“未判定”“所测指标满足”“存在不满足指标”或“部分指标无法评价”。

指标满足与验证完整性分别评价。覆盖要求声明“已覆盖”时，必须绑定至少一个有效当前配置；绑定缺失、结果过时或不适用声明缺少理由会保持待验证。未规划覆盖时报告明确指出尚未评价，不能因为所有运行完成而宣布边界验证完整。

仿真报告不替代实物验证。用于正式设计文档前，应核对模型适用范围、工作条件、求解器警告、测量方法、单位与采样范围，并补充未覆盖的温度、容差、寄生参数和器件极限等验证计划。
