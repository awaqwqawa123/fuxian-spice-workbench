# 伏线 v0.30.3 · 自建库导入与紧凑工作台

本版本把最近验证的器件库、导入和界面改进同步到公开源码及 Windows x64 解压运行包。

- 器件库顶部直接提供“自建库”和“拓展器件”入口，常用器件保留符号预览；入口和网格按侧栏宽度适配。
- 自建库支持选择或拖入 SPICE 模型文件，预览模型、核对引脚并持久保存；重复项跳过，冲突不进行部分写入，保留备份导入导出。
- 统一拓展器件弹窗，集中浏览本地器件、通用器件、自建库及工程模型。
- 支持 LTspice ASC 和 PSpice/SPICE 文件的受支持子集导入，提供依赖缺失诊断。
- 调整紧凑顶栏、菜单、窄栏波形控件与对话框布局，并补充展开收起过渡。

## 下载及启动

下载 `Fuxian-0.30.3-Windows-x64.zip`，完整解压到可写目录，双击 `Fuxian.exe` 或 `启动伏线.cmd`，在启动器中点击“启动软件”。英文入口为 `Launch-Fuxian.cmd`。

包内包含 Windows x64 Node 运行时、锁定依赖、已构建前端、ngspice WebAssembly 引擎、公开模型和对应许可。首次基础使用无需安装 Node 或执行 npm。默认本地地址为 `http://localhost:3032/`；端口被占用时不会结束其他服务。AI 客户端仍需自行安装、登录或配置。

GitHub 自动生成的 Source code 压缩包是源码，普通 Windows 用户请下载本页附带的 Windows-x64.zip。
