# 伏线 · SPICE Workbench v0.29.20 — 首个公开源码快照

在本地网页里绘制原理图、运行真实 ngspice、查看多组波形并编辑 SPICE 模型。

- 原理图编辑、正交接线、网标、复制粘贴、撤销重做。
- 瞬态、AC、DC 扫描、工作点和噪声分析，支持电压、电流、差分探针。
- 多波形视图、测量光标、双轴缩放和中键平移。
- SPICE 模型源码编辑、自建库与可选的模型搜索工作流。
- 可选 stdio MCP 工具，供兼容 AI 客户端读取项目、生成修改候选和调用仿真。
- 本轮增加精确绘图几何缓存，减少无关状态更新触发的画布重绘；顶栏可隐藏全部探针标记。

## 试用

安装 Node.js 24，在源码目录运行：

```sh
npm ci
npm start
```

浏览器打开 `http://localhost:3032/`。基础绘图和仿真不需要 AI 密钥。
