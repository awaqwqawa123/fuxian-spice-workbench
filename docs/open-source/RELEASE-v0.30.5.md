# 伏线 v0.30.5 · 画布、走线与波形

- 画布缩放和平移、侧栏展开和拖动减少重复渲染和布局计算。
- 电路连接检查复用自动走线结果，缩放和切换界面时不反复求解导线路径。仿真点数和精度保持不变。
- 波形图恢复“适配波形”和横向缩放；横轴使用统一单位，减少刻度文字拥挤。
- 多级放大器按实际引脚网络分组排版，保留反馈和参考支路的电气关系。公开源码带有绘图指导与验收规则。

下载 `Fuxian-0.30.5-Windows-x64.zip`，完整解压后双击 `Fuxian.exe`，点击“启动软件”。运行包包含 Node、ngspice、公开模型和第三方许可。可使用同页的 `.sha256` 核对下载完整性。
