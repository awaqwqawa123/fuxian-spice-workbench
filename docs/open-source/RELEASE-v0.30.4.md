# 伏线 v0.30.4 · 工程切换与 AI 工具连接

本版本改善工程切换卡顿，并提供适用于每位用户本机的 AI 接入设置。

- 工程切换只保存与完整工程库修订绑定的当前选择，不再为每次选择验证和重写全部工程。编辑、导入和复制仍执行完整校验与保存。
- 编辑器仅在应用或撤销 AI 方案时读取候选撤销快照；普通渲染和缩放复用未变化的计算与项目摘要。仿真精度、点数与数据保留方式不变。
- “设置 → AI 连接”默认提供 MCP 配置。Codex 导出 TOML，Cursor 导出 JSON；DSH / Harness 提供通用 stdio 参数并说明版本限制。配置使用当前安装的真实路径，不包含连接凭据。
- “设置 → AI 连接 → Codex 程序位置”可自行填写和保存 Codex 可执行文件完整路径，支持带空格和外围引号的 Windows 路径、错误提示及恢复自动检测。修改影响后续连接，已有进程继续运行。
- 桌面共享安装和修复会使用同一份本机程序路径设置，并核对完整共享程序文件；更新路径或路由程序后，旧服务需要重新启动时会明确提示，不会强制结束现有任务。
- 网页 MCP 侧栏显示当前工程同步状态、任务、候选预览和应用/撤销。外部客户端负责对话；接口就绪不代表任何 AI 客户端已成功加载工具。
- 高级桌面共享模式下，在 Codex 桌面发送时会自动请求切回桌面。空闲时立即交接，网页任务或审批尚未完成时保留一条待发消息，安全结束后发送。同 ID 请求去重；手动切换、卸载或桌面断连会取消待发并返回说明。
- 工作台新建的 Codex 桌面共享对话默认使用本机专用工作目录，每工程一个子目录，绘制与解释共用；可设置新工程的根目录，已有会话绑定保留。MCP 外部客户端的聊天归组和工作目录由客户端管理。
- 切换连接模式保留 DSH 当前软件会话内的项目草稿、历史、候选和撤销信息，停止在途请求，不自动重发。修复桌面重连监听顺序，完成任务的重复工具回调可正常返回错误。

## 使用入口

完整解压 `Fuxian-0.30.4-Windows-x64.zip` 到可写目录，双击 `Fuxian.exe` 或 `启动伏线.cmd`，在启动器点击“启动软件”。首次基础绘图和仿真无需安装 Node 或运行 npm。随包 `.sha256` 可核验下载完整性。

程序路径与 MCP 配置会根据每位用户实际环境生成。不要把其他电脑导出的绝对路径原样套用；移动安装目录后重新复制 MCP 配置。Codex 等 AI 客户端仍需自行安装与登录。
