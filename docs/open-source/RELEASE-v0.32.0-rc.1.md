# 伏线 v0.32.0-rc.1

这是 Windows x64 候选版。下载 `Fuxian-0.32.0-rc.1-Windows-x64.zip`，完整解压后双击 `Fuxian.exe`，再点击「启动软件」。基础绘图和仿真可离线使用。稳定版仍可从 v0.30.5 发布页下载。

- **自建库**：直接展示已保存的器件和符号，点击即可放置；导入和备份集中在「导入与管理」。
- **跨工程复制**：在同一网页选中原理图器件，按 Ctrl+C，切换工程后按 Ctrl+V，再点击画布放下。选区内部连线、器件参数和模型随副本保留。
- **导线上放置器件**：把未接线的双端器件拖到直导线上，或在导线上放置新器件。两脚对齐时可串入，原线中段会切开。分支、交叉或探针归属不明确时会提示换一个位置。
- **工程迁移**：本机工程库支持恢复和备份；独立的 `.fuxian` 文件可分享，Windows 启动器可注册文件关联。外部 AI 可通过 MCP 配置连接指定工作区。

换安装目录时，可用自建库的备份导入功能带回旧库。下载页同时提供 SHA-256 校验文件。
