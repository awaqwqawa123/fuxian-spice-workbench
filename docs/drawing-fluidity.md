# 绘图响应优化 · v0.29.5

2026-10-04。依据项目绘图指导 D07，保持真实引脚、显式分支、栅格和单次撤销事务；优化鼠标输入与图形更新的开销。

## 变更

- 器件本体、空白命中区、导线和引脚分别复用已有渲染结果。事件仍读取当前工具、当前工程与当前回调，切换工具不需要重建整个图面。
- 器件拖动只跟随端点所属对象发生变化的导线，包括间接跟随的接点。手工路径在导线及端点对象不变时复用；自动路径仍检查周边环境。
- 放置、探针、接线和框选的预览按动画帧合并，始终处理最新位置；线段沿平行方向或同一吸附位置移动时跳过重复预览。松手使用其自身坐标，取消会清除等待中的预览。
- 一次标签布局共用同一组障碍物。没有探针或探针已有固定标牌位置时，跳过无效的全图避让计算。隐藏节点名时不计算文字布局。
- 保留原有直接更新 SVG 相机的滚轮/平移机制；导航不写入电路。

## 验证方法

`tests/drawing-fluidity-browser.test.ts` 在原生 Chrome、Edge 中加载 300 个器件、300 条导线的压力图，通过真实鼠标输入逐帧核对器件、连接线和连续接线预览。这个测试规模用于测量，不改变产品的工程数量限制。

记录 React Profiler 的实际渲染耗时，检查同一吸附位置的重复移动、线段平行移动、取消及更新的松手坐标。另用可保存的正常小电路检查接线中间折点保持私有，完成接线才保存一次。测试中的输入间隔包含浏览器自动化往返及等待动画帧，不能当作用户界面的帧率。

`tests/canvas-fluidity-browser.test.ts` 检查滚轮累积、指针锚点、平移、缩放极限、即时点击与器件松手。真实 Workbench 回归检查接地和折线跟随、探针选中/删除、撤销、重做及保存恢复；模型、器件数值、探针布局与电气等价另由对应现有测试核对。

浏览器测试各自使用独立的依赖缓存和明确的入口，避免不同图面测试的依赖扫描相互干扰。

## 本机对比记录

同一测试入口、同一 300/300 图、24 个原生鼠标位置，分别加载改动前的主分支源码和本轮源码。Chrome 的 React 实际渲染耗时如下；不是仿真耗时或整个浏览器帧耗时。

| 场景 | 修改前中位数 / P95 | 修改后中位数 / P95 |
| --- | --- | --- |
| 器件及相连导线拖动 | 20.8 / 111.5 ms | 10.8 / 34.5 ms |
| 连续接线预览 | 14.8 / 105.8 ms | 4.7 / 34.9 ms |
| 已移动线段的 20 次平行/同吸附位置输入 | 20 次 React 提交 | 0 次 React 提交 |

Chrome、Edge 都通过原生输入及完整编辑事务验证。Edge 的重复测量受本机负载影响较大，因此不从这些单次样本推断所有设备的固定帧率。回归对重复线段刷新设置明确上限，对耗时输出实测分布，保留比较依据。
