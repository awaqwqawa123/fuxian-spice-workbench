# 模型助手：一句话或方案到模型候选

在“模型助手”的输入框写用途、完整型号、供电和工作范围。例如：

> 用 OPA2376 和 2N7002 做 3.3 V 采集电路，帮我找 SPICE 模型；没有官网模型就按规格书调整库内相似器件。

多个明确型号会自动建立独立任务，保留完整方案背景，依次执行。每个器件有独立会话、规格书和候选；可以停止整个方案。失败的输入、历史结果和来源会保留，重新载入页面不会自动再次联网。继续原任务只处理其绑定型号。

## 自动流程

1. 搜索准确型号，优先下载可追溯的厂商官网模型；没有官网模型时检查已有目录及登记公开来源。
2. 核对真实源码、目标定义、依赖和导入兼容性。辅助子电路不会冒充目标器件。已下载的完整源码、许可和诊断可查看或保存；暂不兼容不等于厂商没有模型。
3. 未取得目标模型时自动搜索、下载并提取厂商规格书。上传的 PDF / TXT 也能参与同一流程。
4. 单器件模板按完整型号证据、类型、极性、已知方程类型及可映射参数排序；先比较整个可用库，再限量返回候选。提供比较依据、未知项及继承假设，数值接近不表示器件等效。
5. 对有明确典型值、测试条件和页码的参数生成 `APPROX` 候选，列出原模板、改前/改后数值、原文依据和局限。没有可靠参数映射时显示具体缺口。
6. 用户审阅后导入工程或存入自建库；搜索和生成候选不直接改变原理图。

这条自动流程适用于 Codex、Cursor、DeepSeek 本机和 API 四种模型助手入口。明确要求修改一个已有参数的任务仍会交由推理助手核对，不会把未修改的原模型报告成调整结果。

## 改参边界

二极管支持有条件的 BV/IBV 成对近似和零偏 CJO；BJT 支持有 IC/VCE 条件的典型 hFE 作为 BF 初始近似；MOS 支持有 ID 条件的典型 VGS(th) 作为 VTO 初始近似。其余参数继承模板。JFET 截止电压、非零偏电容、最大额定值或模糊数值列不能自动替代模型方程参数。已有显式用户参数和审核过的三端分流基准映射仍可使用。

运放适配只接受已有、来源可追溯、端序明确，且增益及主极点参数作用已证明的单通道模型。它可以调整规格书有明确单位和条件的典型增益/带宽，不从零生成运放，也不把双/四通道封装或继承的噪声、压摆率、共模与输出能力声称为已验证。目前安装库尚未找到符合这个窄范围适配器的运放模板；不支持任意厂商宏模型改参、曲线拟合或加密模型解密。

2026-10-02 实际联网检查能找到并下载 TI 的 OPAx376 PSpice/TINA-TI Rev. F 模型。当前导入器不能解析其主模型的 PARAMS 表头及 VSWITCH 等语法，因此该例仍显示真实源码与兼容性原因，不能宣称已在工作台成功仿真 OPA2376。

## 验证

新增回归覆盖真实客户端到服务端工具的完整交接、典型参数提取和排序、四种入口的准确型号自动流程、条件回退指令、原文件保留、多器件串行执行、停止、重试及存储恢复。ngspice 验证派生 BJT 可求解，以及审核运放拓扑改参后的直流增益和交流带宽变化。测试中的合成模板只用于验证流程和方程，不作为厂商模型分发。
