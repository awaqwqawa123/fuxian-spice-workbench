# 原理图绘制验收指南

本指南用于手绘、导入整理、AI 候选和重新排版后的验收，与[绘图指导](drawing-guide.md)、[布局模式](drawing-patterns.md)配套。它规定后续工作的通过条件，不表示当前产品已经实现或通过全部项目。
依据为[LTspice 全库扫描与 32 图精读](research/2026-09-25-ltspice-full-library-census.md)、[公开范例研究](research/2026-09-25-online-schematic-references.md)及[实现差距审计](research/2026-09-25-drawing-gap-audit.md)。4,283 份文件的结构扫描不能代替功能理解、GUI 操作或求解器验证。

## 1. 绘制前：冻结基线与操作意图

1. 保存工程副本、基线版本、规范化网表及器件/模型清单；浏览器测试使用独立测试工程，保留用户当前未保存内容。
2. 明确本次是纯排版、保持连接的拖动，还是用户明确授权的电气修改；把允许改变的对象和参数写入记录。
3. 记录引脚语义、显式网名、输入/输出、探针、仿真配置；声明锁定区域和已认可的局部布局。
4. 按布局模式辨识主通道、反馈、供电、对称/耦合和重复单元；不能确定功能时保留原连接并标记待确认。
5. 为正交走线和文字预留空间，使用工作台当前电气栅格；不得直接把 LTspice 的图纸单位当 SVG 像素。

## 2. 电气硬性不变项

以下约束适用于纯排版。新建电路按设计要求核对；电气修改则逐项记录明确授权的差异，不能借整理图面偷偷改电路。

| 对象 | 必须满足 |
| --- | --- |
| 引脚 | 每个器件 ID、引脚身份、引脚到网络的映射不变；旋转/镜像只变几何，不能交换运放正负端、MOS 的 D/G/S、变压器极性。 |
| 器件与模型 | 位号、型号、参数、模型定义及引用、子电路引脚顺序、行为源表达式不变；新增或未应用的候选器件不能丢失。 |
| 命名网络 | 显式网名和别名关系不变，尤其保留数字网名；自动网号变化须给出一一对应关系，不能掩盖网络合并或拆分。 |
| 网表 | 比较规范化后的器件参数及引脚连接图等价；只忽略行序/无关空白和有映射证据的自动网号，不能忽略极性或节点顺序。 |
| 输出与探针 | 输出端、电压/差分探针端点、电流测量支路及正方向不变；合并重合线后迁移引用，支路歧义必须提示重新放置。 |
| 仿真与工程 | 配置、结果所属配置、波形曲线表达式及项目绑定保持；保存重开与撤销后重新核对上述项。 |

规范化网表相同能证明连接与参数未变，不能证明画面清晰；仿真曲线相近也不能替代引脚映射检查。仅改布局时不必重复大规模仿真；涉及连接生成、模型或探针支路变化时运行相应 ngspice 用例并保存真实输出。

### 真实探针交付检查

1. 从用户观察目标列出需要的电压、电流和差分测量，核对 `Project.probes` 的完整记录（最多 64 项）。画布上的输出三角、网标或文字注释不能作为已放探针的证据。
2. 每项记录有唯一 ID、明确类型与真实端点/器件/导线支路；差分按正端减负端，电流正方向可解释。导线切分或归并后即使 ID 相同，也要核对 KCL 支路含义；不明确就给出具体诊断，不能改用最近器件的值。
3. 预览可见 V/I/ΔV 类型和引线，标牌避开位号、值和导线。应用后工具栏、画布及波形引用同一批测量；仅有预览装饰而没有可选择曲线不通过。
4. 执行应用 → 撤销 → 重做 → 保存重开，核对全部探针与视觉偏移；纯重画只改变几何，保留测量目标与方向。用户后续增删探针不能被旧候选静默覆盖。
5. 有仿真结果时核对对应节点、支路和差分曲线；没有结果时明确尚未运行，不显示编造数值。缓启动案例核对 Gate、LOAD_DRAIN、R1 电流，负载压降按目标选配；其他电路使用自己的测量清单。
6. 工具参数错误、端点不存在、支路歧义与超过数量上限分别有明确字段反馈，失败不改变原候选。旧会话没有新工具 schema 时走已支持的兼容入口或报告限制，重启服务本身不能当成新工具可调用的证据。

### 波形配置交付检查

1. 图内核对配置名称、分析类型/区间/步长、各 plot 的实际曲线、显示窗口与光标；对话和候选摘要关于配置只给仿真类型、范围与步长。不存在的配置/探针明确标出，不自动换成默认输出；配置数据仍随候选完整交付。
2. 同一个图框的多个 plot 使用同一仿真配置；独立图框允许选择不同配置，或共享配置而采用不同显示窗口。核对瞬态线性时间、AC 对数频率、DC 负起点，以及 `domain:[0,0.25]` 不改变分析 stop。
3. 原理图和波形图框同页放置，图框与器件/文字留有独立空间；缩放图框不能改变求解数据或背景画布倍率。
4. 配置预览不显示假波形；只有与项目和配置匹配的真实 Result 才能画曲线或报告测量。仅缺少 Result 的只读预览不判定服务端从未运行。
5. 应用 → 撤销 → 重做 → 保存重开，核对配置关联、图框位置、plot 布局、曲线 ID 和显示范围全部恢复；纯排版保留它们，用户后来新增的图框不被旧候选静默覆盖。

## 3. 几何硬性检查

验收时固定栅格 `g`、坐标容差 `ε`、字体和视口。`ε` 只吸收浮点误差且应远小于 `g`，不得用扩大容差放过可见碰撞。所有边界包含实际变换后的符号和文字，而非仅用器件锚点猜测。

| 检查项 | 通过条件 |
| --- | --- |
| 端点/出口 | 端点误差 ≤ `ε`；首段从源引脚沿朝外方向引出，目标引脚指向倒数第二点的向量沿目标朝外方向。四方向与镜像均成立。 |
| 穿体 | 排除符号定义的合法引脚通道后，导线穿越本体计数为 0；端点所属器件同样参与检查。 |
| 文字 | 导线穿越非关联文字、文字相互遮挡、文字压住无关符号均为 0；自己的位号/数值同样不能成为路由盲区。合法标签引线只连接指定锚点。 |
| 直角/冗余 | 新绘正交路径每段满足 `abs(dx) ≤ ε` 或 `abs(dy) ≤ ε`；无零长度段、无无意义回折。导入的既有斜线先保持连接，不能直接删除。 |
| 重合/交叉 | 不同网无共线正长度重叠；同网重合提交后形成真实公共段且保留分支；普通十字交叉不自动接通。 |
| 节点/网标 | 实心点仅表示显式分支，二路续接平时不画点；自动名每网最多一处，显式网标/探针标牌不得遮住关键引脚。 |
| 统一边界 | 画布、预览、路由避障、框选、适配和 SVG 导出使用一致的变换/文字边界；长型号、中文、负坐标不裁切。 |

找不到零穿体、零穿字路径时，应定位失败线段并保留待整理候选，不能仅因“碰撞评分最低”判为成功。折点数、总线长和绕行量记录为优化指标；不能为减小这些数值牺牲反馈可读性或真实连接。

## 5. 功能可读性：必须有人看图

- 沿主信号/功率通道能顺序读出功能，供电和去耦不被排成信号级；输入左、输出右是默认习惯，不能强迫所有电路横排。
- 反馈返回路径可追踪，反馈与输入/输出互不遮挡；运放双反馈、差分对、桥臂、磁性耦合的局部结构保持完整。
- 对称支路与重复相位有统一间距，但不为视觉对称交换端口或合并采样线；多输出电源允许向左右展开。
- 网标用于减少远距离杂线，同时保留理解电路所需的关键回路；评审者能指出每个标签实际代表的网络。
- 无法识别的结构或性能预算不足时，保留已知良好的局部布局并给出原因，不能把“全部器件不重叠”当作清晰方案。

## 6. 真实浏览器连续操作

复制与网络高亮专项：连续 Ctrl+C / Ctrl+V 和按钮入口均检查；输入框保留系统快捷键。只选两个器件本体也应复制它们之间的连接点路径，粘贴后不引用原组端子；含厂商模型及无模型有序端口的器件分别执行保存重开、一次撤销/重做。选区内 V/I/ΔV 探针的编号、端点、导线锚点和电流方向随新 ID 同步。普通点击引脚、导线、连接点或标签应按编译网络高亮远端同名标签，不能把几何交叉当连通；不可因高亮改写图形拓扑。渲染性能记录静止轮询前后真实 React 提交次数，不能以加入 memo 作为通过证据。JSDOM、HTTP 和求解器测试分别记录，不能算作真实浏览器图面验收。

1. 在独立测试项目中拖动双端器件、多端运放/MOS、T 分支和已布线段，横向、纵向并跨过原拐点；确认每个端点随动、无斜线、无全图意外重排。
2. 拖动中短按右键或 Esc 取消，坐标、路径、拓扑全部回基线且不留多余历史；正式提交后一次撤销恢复，重做再现。正常状态下右键菜单、长按右键/中键平移分别检查。
3. 在 25%、100%、400% 画布缩放及左右栏收起/展开/调宽状态下重复移动与框选；记录实际容器大小，确认图形等比、光标吸附无偏移、文字位置稳定。
4. 比较同一文字、节点和探针在两次缩放下的屏幕尺寸比与画布倍率比，允许字体栅格化误差；可见图形不能被最小命中区反向放大，透明命中区可以保留可操作尺寸。
5. 选中嵌入波形图后滚轮改变图框在画布的占地及标题/刻度/图例比例；记录图框尺寸、画布 `viewBox`、曲线数据域，后两者不得因此变化。还须覆盖未运行、运行中、错误、准备中、无曲线与直流工作点状态；它们与正常波形使用同一缩放坐标系，不能只给部分文字乘缩放系数，不能以最小可见字号使小图框文字停止缩小。
6. 波形双击放大、弹窗内缩放、关闭/Esc 后原图框仍在且配置不丢；多图框、图内多视图、复制粘贴后选择归属明确，操作不影响其他图框。
7. 保存重开并导出 SVG，对照图面、网表和探针；浏览器截图只证明实际查看的倍率/状态，不能替代未执行场景。

## 7. “不好看，重画”的候选闭环

1. 基于当前画布或基准仍有效的最近未应用候选重排；候选中新增的器件/参数必须保留，显示实际几何差异与电气差异。
2. 相同策略重复执行无变化时明确提示，不制造假候选；“反馈在上”等约束只有被执行并验证后才可声称满足。
3. 预览 → 应用 → 撤销 → 重复应用 → 再撤销，逐步比对几何/网表；保存重开后继续该候选，不能重复插入器件或丢失基线。
4. 手工修改画布后再应用旧候选，应检查基准冲突；本地排版、可写 Codex 请求和桌面占用错误分别记录，不将本地结果宣称为模型理解或解锁成功。
5. 等价地线重新分段不能因为导线/连接点编号变化而被误拒；应比较真实器件引脚网络、显式网名、参数、模型与配置。此比较不等于电流探针仍指向同一支路；应用阶段另核对测量引用及正方向。复现例见 [2N7002 / RC 对照记录](artifacts/2026-09-25-protection-redraw/README.md)，对应纯布局等价与候选完成回归测试。

## 导线删除与直流控制补充（2026-10-11）

- 删除导线时按实际附着关系删除电压、差分和导线电流探针，不能因为其电气端点仍存在而把它留在另一段线上。同网的其它存活线段探针应保留。删除、撤销、重做分别核对画布、顶栏记录和保存/重开后的引用。
- 删除和共线合并是两种生命周期：合并保留显式迁移，删除移除原附着探针。不得用删探针掩盖错误合并或把交叉认成导通。
- 直流电压/电流图标必须分别显示真实开关状态；展开、调整大小和收起详情不清空结果或关闭画布标注。计算中、失败、陈旧结果及无唯一导线电流仍明确提示，不得把缺值显示为 0。
- 调整后的工作点详情在窄画布和侧栏同时展开时，应能访问收起按钮并受容器边界约束；组件测试不替代真实浏览器的可见区域检查。


### 2026-10-12 探针 / 复制 / 波形坐标交接回归

- 在已有 8 个真实测量时再放第 9 个；复制含探针器件后数量超过 8 也必须完整保留。项目解析、工具 schema、UI 与粘贴统一使用 64 个预算，超过预算原子拒绝并明确报错，不静默丢测量。
- 电流探针点击唯一连接导线的引脚应绑定该真实支路；分叉点及理想导线环路仍要求明确导线或报告电流不唯一。已有电压 tip 覆盖导线时，切换电流 / 差分工具可以在真实锚点继续放测量；同类型探针与标牌拖动保持原有含义。

### 2026-10-17 精确渲染缓存与探针显隐
