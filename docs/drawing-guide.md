版本：1.2 · 2026-09-25。适用：新原理图、已有图的排版、AI 候选图、手工编辑交互及绘图代码修改。

补充实证：[2026-10-02 绘图质量总结](research/2026-10-02-schematic-quality-study.md)核对了 U112 异网重叠与 R53/C28 同网折返、40份在线电路文档、3份补充资料和50个本地例子（十倍扩读版，含逐例证据及计数审计）。该报告明确区分已验证问题、参考规律与尚待实现的改进，不把已有规则或测试通过视为真实图面合格。

本地阅读已从80项候选方案扩展到[全库结构阅读与绘图经验](research/2026-10-02-whole-library-drawing-review.md)：4,334份LTspice ASC、实际使用的原始ASY，以及85页PSpice CSA和213份NET/CIR均有逐文件记录；Capture确认cascode一页原生图，其余32份按用户要求暂止。另有[12例LTspice补充复核](research/2026-10-02-ltspice-focused-followup.md)，细化直连、T分支和必要反馈回线的适用条件。[早期80例方案](research/2026-10-02-local-pspice-ltspice-reading-plan.md)保留为历史阶段。自动结构读取与原生图面审阅分别计数。

以后执行这些任务时，先读本文件，再按电路类型查 [典型电路画法](drawing-patterns.md)，完成后按 [绘图验收](drawing-acceptance.md) 检查。研究报告用于追溯依据，本文件用于决定实际怎么画。

## 目标与规则优先级

2026-10-02 绘图器已落实近邻同名网络的实体端点连接、合法路径优先、异网引脚保护、共享接点局部对齐，以及画布/避障/SVG 共用文字位置。真实完整电路和候选应用/撤销/保存回归见[本轮交付](artifacts/drawing-router-fix-20261002/README.md)。这份实证不代表功能分区、任意手工文字偏移等全部目标已实现；新生成或明确整理候选才使用这些修复，读取旧图不静默重写保存数据。

一张合格图应当同时满足：电气连接可信、功能关系易读、文字和接线清楚、局部编辑可预测。

1. 用户当前明确要求优先，尤其是要保留的布局、朝向、手工折点和项目状态。
2. D01、D03、D04、D08 的电气及事务约束必须满足。不能为美观改变网络、模型或引脚。
3. 图面质量按 D02、D05、D06、D07、D09、D10 处理。输入在左、反馈在上等属于默认策略，可因电路结构改变；无穿体、无文字遮挡是交付检查项。
4. 不确定器件功能时，使用已确认的真实引脚和连通关系，保留已有功能块；不能仅凭器件名称、坐标或相邻距离猜接线。

这些是目标规则，**不表示当前编辑器已实现每项能力**。遇到缺失能力，记录具体限制及未通过项，不能以“已调用自动排版”代替验收。

## 开画之前

- 读取当前工程、候选版本、模型定义、引脚顺序、网标、输出、探针和分析配置。确认任务是新建电路、改电气设计，还是只整理现有图。
- 对已有图建立电气基线：元件编号/类型/数值/模型、引脚网络、耦合关系、命名网络与测量引用。几何坐标和中间折点单独记录。
- 标出已知功能块：输入、主信号或功率路径、输出、反馈、偏置、供电、控制/时钟、测量。依据实际连接与模型引脚识别；未知的先保留。
- 从 [典型电路画法](drawing-patterns.md) 选择结构；复杂电路可组合多个局部画法，不要求一张图只有一个信号源或一条阅读方向。
- 明确要保持的手工位置、图框和注释。普通参数修改、开关侧栏、缩放不触发全图重排。

## D01　电气关系先于图形位置

- 端点必须引用真实器件引脚或显式连接点；不能用“线看起来碰到了”代替电连接。
- 符号旋转、镜像时变换引脚坐标及出口方向，保留 SPICE 引脚身份与顺序。不能按上下位置猜正负输入、D/G/S 或供电脚。
- 纯排版保留器件类型、数值、模型代码、模型来源、源波形、分析配置、耦合关系与命名网络。只允许改变图面几何及等价的线段表示。
- 重排/合并前后比较规范化电气网络。自动节点编号或内部线段编号可变化，但同名器件的各引脚应属于等价网络；不能只比导线数量。
- 变压器 K 耦合、受控源的控制量、网络标签都携带电气关系，不能忽略，也不能凭磁耦合新增电连接。

## D02　先排功能块，再排块内器件

- 单通道模拟电路默认输入左、输出右；对地支路向下，偏置和电源留在外围或独立区域。
- 运放留出反馈外圈；差分对/电流镜保留成对关系；变压器保留绕组组合；多相电源按相位单元重复；多输出允许向两侧展开。
- 主信号/功率路径先占清楚的通道，再安排反馈、控制和供电。不要让共地或公共电源把所有器件吸到同一层。
- 开关负载图先沿真实引脚和网表逐段标出供电、保护、负载、开关 D/S 与回流，让负载成为输出区域的视觉终点。低边 NMOS 常见路径是供电→负载→D→S→地；高边 NMOS 源极跟随结构可为供电→D→S→负载→地，源极到地的电阻此时就是负载，不能擅自改成低边电路。路径向右时可令 D 在左、S 在右、负载置最右并向下接地；路径向下时 D 在上、S 在下，Gate 留在控制侧。只有核对网表和设计目标发现接线错误时才改接并重新仿真。
- 对齐实际引脚所在的通道和相同功能块；器件原点、符号中心不必机械地排在同一直线上。
- 电源/地网标可减少跨区长线，但不能在只重排任务中擅自改变网络名称或电气归属。
- 无法识别的闭环或双向电路保留人工分区。普通无方向图的距离分层可以作为初稿，不能直接当可读性验收结果。

## D03　从引脚朝外出线，从目标引脚外侧回接

- 出口方向来自符号的引脚定义，不能统一用“引脚相对中心的方向”替代所有多端器件。
- 新生成导线默认正交，先留出可辨认的直线引脚通道再转弯。以本工程实际电气栅格 G 为基准，1–2G 出口留白可作为起点，按符号和邻线调整；这不是固定屏幕像素。
- 若路径按 `p0 → … → pn` 排列：`p1 - p0` 应沿源引脚朝外方向；`p(n-1) - pn` 应沿目标引脚朝外方向。目标端已经反向取向量时不要再把出口方向取反。
- 本体是障碍物，两端器件也不能整体从避障中排除。仅允许经过合法引脚通道，禁止穿入器件后折返。
- 手工折点在不破坏连接和明确用户意图时保留。自动布线无合法路径，应定位冲突并保留原图/候选，不能把“碰撞最少”的坏路径当成功。
- 导入带斜线的原图时保留真实连接。正交化属于单独的几何改动，不得借机连接原本无连接的交叉点。
- **已存旧路径反例：**R2 在 `(500,320)` 从竖直转为水平、`rotation=180` 后，W3/W4 仍沿 `x=500` 穿过本体。读取旧工程时可依真实左右引脚出口局部修正无手工折点的显示路径，保持网络及原项目不变；再次旋转/镜像时从新引脚朝外引出，远端与无关线段保持。绕开本体后还须查 R2 位号与 `1Meg` 值的实际文字边界，不能靠白色文字底色遮住导线伪装避让。R2 图面和数据见 [旋转与波形验收记录](artifacts/2026-09-25-rotation-waveform/README.md)。

## D04　交叉、分支与重合分别处理

- 实心点只表示真实分支。直线续接和普通二路拐角平时不画实心点；编辑手柄与电气连接点区分。
- 普通交叉不自动连接。生成图应避免让无关网络长距离共线重合，这种图面有歧义，即使网表暂时未短接也不合格。
- 手工编辑提交后的正长度重合按项目既定规则归并为真实公共线段，保留分支并迁移网标、输出和探针。纯重排不能利用这种归并偷偷接通不同网络。
- 同网干线可共享；不同网交叉需要明确保持不连接。不要用微小折点、重叠的两根线或隐藏分支来掩盖问题。
- 电流探针原分支在归并后不明确时标记需要重新定位，不能选一个近邻元件电流代替。

## D05　把文字当作有位置的图形对象

- 位号、数值、型号、网标、源表达式和说明有不同职责，分别分配锚点、对齐和留白。不要把所有字段固定在右上角。
- 水平二端元件通常可把位号/值分置上下；竖直元件通常在侧面排字；三端及多端器件先避开各引脚和反馈路线。具体位置服从真实空间。
- 文字位置可独立调整，保存偏移；移动文字不改变器件位置或电气网络。用户已固定的位置不被普通参数编辑或缩放覆盖。
- 旋转/镜像后重新计算默认文字位置与实际边界，保持可读；长型号、中文、多行源参数均参与测量。
- 画布渲染、走线避障、框选/适配、候选预览与 SVG 导出共用符号和文字几何依据，不能各自猜一份偏移和字号。
- 长模型定义放在现有模型编辑入口；图面可显示足够辨识的摘要，但不能让显示值与实际参数不一致。

### 测量探针随电路一起交付

- 新建或按目标完善电路时，先确认要观察的节点、电压差或电流支路，把真实测量存入 `Project.probes`（最多 64 项）。调用 `set_measurement_probes({probes:[...]})` 提交完整探针列表；它是替换列表，必须保留用户已有且仍有效的测量，不能把 `drawing.output` 的单输出三角或文字标签当成多个探针。
- 电压使用 `kind:"voltage"` 和真实 `positive` 端点；差分仍用 `kind:"voltage"`，同时给出 `positive`、`negative`，结果为正端减负端。器件电流使用 `kind:"current",device:"R1"`；导线电流须给出已确认的实际导线支路及方向，不能用邻近器件电流代替。
- 探针数量和目标服从电路目的。例如本项目缓启动先观察 Gate、LOAD_DRAIN 和 R1 负载电流；需要负载两端压降时再放差分探针。先从真实网标/引脚核对目标，不把这组位号或固定四针套到所有电路。
- 纯重画保留测量 ID、类型、正负端和电流方向，只调整随新布局变化的视觉锚点与标牌偏移。引线、V/I/ΔV 标识及标签留出空间；移动标牌不能改变测量目标。
- 设置失败时按工具返回的具体字段、缺失端点或不明确支路修正；不改原工程、不删除用户探针绕过检查。成功后重新 `inspect_circuit` 核对持久化探针，再按验收指南检查预览、应用和撤销。放置成功不等于已仿真，数值只来自真实求解结果。

### 波形图、曲线与仿真配置随方案交付

- 生成用于仿真的电路时，除真实探针外，通过 `configure_waveforms` 配置 `Project.waveformSetup`：`version:1`、`profiles:SimulationProfiles`、`diagrams:CanvasWaveform[]`。先核对 inspect 返回的工具 schema；不依赖浏览器中的旧图框状态。
- 每个图框绑定一个存在的仿真配置，图内 1/2/4 个 plot 使用同一分析结果。曲线 ID 使用实际 `probe:P1`、`voltage:v(...)` 等支持的引用，不把显示标签当 ID；电压、电流可分 plot 观察，主曲线和差分极性保持明确。
- 按测量目标设置分析类型、区间和步长；例如缓启动全程与启动细节可以共享 600 ms 仿真配置，细节图用 `domain:[0,0.25]` 显示 0–150 ms。不能把显示窗口当成分析截止时间；AC 的局部范围按对数频率解释，DC 保留负起点。
- 图框在原理图同一画布独占空间，曲线、plot、显示区间和光标等配置在图内查看；对话和候选摘要关于配置只给仿真类型、分析范围与步长。无匹配求解结果时显示配置说明，不合成曲线，也不能仅凭预览没有 Result 声称服务端从未运行。
- 保留已有图框、配置、曲线选择和窗口；用户明确要求修改时生成可审阅候选。应用、撤销、重做及保存重开后，电路、探针、配置和图框必须属于同一方案。

## D06　间距由占地和通道决定

- G 是当前有效电气吸附栅格；LTspice 的 16 坐标单位、KiCad 的 50 mil 都不能直接映射为本产品 SVG 像素。
- 先按引脚栅格摆放，再考虑器件本体、文字矩形、反馈通道和探针占地。两个中心点距离足够不代表文字不重叠。
- 可用 1G 可视留白、2G 平行通道间距作为初始建议，遇到宽字段/大符号增大。最终以实际碰撞检查和可读性为准，不能为了达到数值删除或改接电路。
- 允许负坐标、大幅面、上下分区和外围长反馈。适配范围计算包含文字、注释及波形框，不只包含器件中心。
- 显示栅格密度、文字微调步长与电气引脚吸附分开管理，外观设置不能悄悄移走电气端点。

## D07　接线、拖动和缩放各有边界

- 默认拖动器件保持所有已接引脚及真实分支；拖线段局部改变路径，不重排整图。若提供会断开连接的移动操作，应有独立明确入口。
- 接线预览与已提交路径分开；短按右键先取消当前放置/接线/探针等活动工具，普通状态才开菜单。长按右键或按住中键拖动平移。
- 画布滚轮以指针为中心缩放。选中波形图时按用户既定规则调整图框在画布的占地，不能被背后的画布缩放抢走。
- 器件、导线、节点、探针及图面文字使用一致的画布缩放。透明命中区可保留最小屏幕尺寸，可见图形不应因此异常放大。
- 侧栏宽度改变只改变可用视口，不把器件横向拉伸。图框标题、刻度和图例随外框尺寸合理变化；放大浮层关闭后原图框仍在。

## D08　编辑是可恢复的事务

- 一次完成的拖动、旋转、布线或候选应用对应一次撤销记录；预览中的每个鼠标移动不单独入栈。
- 取消恢复开始前的位置、路径、连接、标签及探针引用。撤销/重做覆盖整次变更，不只恢复器件中心。
- 对选区进行复制或移动时保持组内几何和连接；处理跨选区边界的端点与网标作用域，不因同名复制意外连接两组电路。
- 器件本体选区的组内连接包括中间连接点路径，不能只复制直接器件到器件的导线；通往未选器件的支路不能粘回原端子。复制快照保留 `pins` / `pinPositions`、参数、模型原符号与来源、源设置和选区内探针；无模型的子电路仍保留已知端口顺序。统一重编号后核对导线、网标、输出、探针端点及电流方向，重复 ID 须报告冲突字段，不能猜测。
- 保存/重开、复制、应用/撤销之后再检查字段位置、波形配置和引用；不覆盖用户未保存输入或无关工程。

## D09　“重画”应体现具体的排版目标

- “画得不好，重画”默认生成纯布局候选；“改阻值/更换型号/改变功能”属于电气任务。明确说明改动范围。
- 从仍匹配当前画布基线的最近待审阅候选继续，保留未应用的新器件和参数；基线冲突时不能覆盖用户后续编辑。
- 先识别问题，再选策略：例如反馈放上侧、差分对对称、输入与偏置分区、展开拥挤区域、保留已选区域。只随机挪位置或反复执行同一分层算法不算新的排版策略。
- 同一策略保持确定性；没有几何变化就如实说明。存在变化时简述调整了哪个功能块、哪条反馈、哪些标签。
- 实作时复制 `inspect_circuit` 返回的完整候选，在原器件对象上修改坐标/朝向，在原导线上修改折点；不要按位号和数值摘要重建器件而丢掉 `params`。完整 `drawing` 保留 `labels`、`sourceId`、`output`，项目保留源设置、模型和测量。优先保留导线 ID 与端点引用；确需等价拆分线段时，核对引脚网络并迁移输出、网标、探针引用，不能把线段数量改变直接视为电气改变。
- 提交被拒绝时，候选仍是上一份成功版本。依据返回的具体字段和前后差异修改后重试；不能通过删参数、换模型或放松纯排版限制绕过检查。只有提交成功、重新检查取得实际几何变化且电气校验通过，才说明重画候选已生成；说明图面尚未验证的项目。
- 展示候选预览与实际差异，沿用应用/撤销流程。纯排版不能凭已有仿真声称新电气设计已验证，电气改动需按现有流程校验与真实仿真。

## D10　图画完后才判断是否合格

依次检查：电气等价 → 引脚出口与正交 → 本体/文字/无关线冲突 → 功能块可读性 → 编辑与缩放 → 保存/导出一致性。完整步骤和记录模板见 [绘图验收](drawing-acceptance.md)。

“正交”“网表没变”“构建通过”各只证明一部分。必须用代表性图检查真实画面；功能关系可读性需要人工审图，静态扫描不能替代。

已知优先修复点：目标端方向评分可能使线穿入目标本体，理想运放的实际标签位置与路由文字障碍不一致。具体输入、坐标与代码证据见 [差距审计](research/2026-09-25-drawing-gap-audit.md)。此指导文件不把这些问题标成已修复。

## 绘图器落实记录（2026-10-13）

`inspect_circuit` 与 `validate_circuit` 增加 `drawingQuality`，使用与路由/导出共用的引脚、符号本体、位号/数值边界检查估计冲突。分类包含本体互压、文字互压/压本体、穿体/穿字、异网共线、引脚出口不符及路线折返；返回具体对象编号和位置，不修改源图，也不把几何问题混成电气 valid。普通交叉不报异网重合，同名网依据真实标签身份比较，不能从像素推断连接。

检查在助手读取/验证时运行，不进入每帧渲染。冲突列表最多 120 项，计数与 omitted 分开；计算预算达到或引用无效时 complete=false，明确表示检查未完成。文字范围是估计，未包含探针标牌、波形图框和完整原始厂商图元；零估计冲突不能代替浏览器人工审图。自定义 X 器件的端口名称按 pins 顺序，outward 直接使用路由器 terminalLeadDirection，避免摘要另猜方向。

明确本地重画新增真实 sourceId/output 路径识别：简单 RC/RLC 主链按变换后的引脚轴组织，对地支路移到主链侧方；单个 OP/OPA 的直接输出→输入无源反馈按真实输入侧安排独立层，已确认供电另分区。未知多端、桥式、多运放、浮地、混合主轴或主路径过长时退回一般布局，不依据名称补线或强行横排。中文/全宽文字边界不再按 UTF-16 字符数量低估；普通缩放和参数修改不挪默认锚点。前后静态图与限制见 [实施图面记录](artifacts/drawing-experience-20261013/README.md)。
