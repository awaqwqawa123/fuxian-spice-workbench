# 接地与网络符号

器件库的“接地与网络符号”提供标准接地、信号地、机壳地，VCC / VDD / VSS / VEE 电源端口，以及输入、输出、双向网络端口。点击后放置到引脚、导线或空白处，也可以直接拖入画布。放置前按 R 旋转，按 Esc 取消。

电源端口用于命名网络，实际供电由电压源提供。同名网络不区分大小写并自动互连。三种接地样式均对应仿真的零电位节点；外观不建立额外的隔离地或保护接地模型。

选择网络符号后，在右侧编辑名称、样式和方向并应用。选择接地器件后可切换接地样式。独立端口可以拖动，连接点及关联导线跟随；附着于器件引脚的符号随器件移动。复制端口会沿用原有的名称去重规则，避免副本误接到原网络。

工程 JSON 保存全部样式和旋转；SVG 和报告使用与画布一致的图形。LTspice ASC 保留网络名称及 In / Out / BiDir 端口语义，并恢复常用电源网络和标准信号地。ASC 仍会重新排版；机壳地、保护地外观、自定义电源名称的箭头及自定义旋转请通过工程 JSON 保存。
