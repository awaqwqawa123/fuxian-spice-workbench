# 自建库、跨画布复制与导线串接实施计划

**目标：** 从左侧自建库重新使用已保存的模型；把原理图选区复制到另一个工程；将两端器件串入已有线路。

**实现：** 三个独立工作树并行实施。自建库负责库视图、读取反馈及导入入口；剪贴板负责 App 至编辑器的交接与依赖；串接负责画布放置、拖拽、导线拓扑与一次撤销。编辑器的剪贴板处理与串接提交分开修改。

1. 自建库：检查从已有本机库恢复卡片、保留符号、放置器件和导入备份，分别验证加载中、空库和读取失败。
2. 跨画布：使用两个真实工程重复复制、切换、粘贴；核对新位号、内部连线、模型及符号；确认普通文本输入仍能复制粘贴。
3. 串接：依照绘图指导，用实际引脚对齐横线及竖线，移除器件两端之间的旧导线；保留外侧导线和有效引用；分支等不明确位置不自动改线。核对一次撤销和重做、生成网表及 ngspice 结果。
4. 集成：合并三个工作树提交，运行生产构建与回归，在独立本机端口、测试工程和测试库中用内置浏览器验收。
