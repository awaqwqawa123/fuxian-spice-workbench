# 搜索站点登录

工作台支持为半导小芯、立创商城、Google 和 AllDataSheet 保存独立的本机浏览器会话。它使用电脑上已安装的 Edge，未找到时使用 Chrome；不需要另装浏览器。

## 操作步骤

1. 打开模型搜索窗口，点击“连接搜索站点”。
2. 在需要的站点下点击“打开浏览器登录”。工作台会打开该站点的专用浏览器窗口。
3. 在原站自行登录或完成它要求的验证，然后回到工作台，点击“我已完成，检查连接”。
4. 检查通过后重新搜索型号，搜索服务会复用这个站点的浏览器会话。

第一次需要在专用窗口登录一次，日常浏览器的登录状态不会自动复制进来。工作台不需要用户粘贴 Cookie，也不会接收登录密码。

## 状态含义

- **未连接**：尚未启用该站点的专用浏览器会话，搜索仍使用公开访问方式。
- **登录窗口已打开**：窗口已打开，尚未证明搜索可用。
- **会话已保存**：本机浏览器资料已保留，当前登录是否有效仍需检查。
- **连接可用**：已实际读取到站内搜索结果。它不代表该站点一定有目标型号或 SPICE 模型。
- **需要操作**：站点仍要求登录或验证，应在专用窗口完成。
- **连接异常**：本次访问没有完成，界面会提供重试提示。

站点可能使登录过期，部分仅在当前浏览器运行期间有效的 Cookie 也可能在关闭后失效。此时重新打开窗口登录并检查；保存会话不等于永久登录。网站本身不允许的访问不会被标成“未找到型号”或“连接成功”。

## 本地资料

Windows 默认位置为 `%LOCALAPPDATA%\SpiceWorkbench\site-sessions\v1\`，四个站点各使用一个子目录。Cookie 和站内存储由专用浏览器管理，不会放进电路工程、Git 仓库、模型提示词或状态接口中。不要上传或分享这个目录。

“清除本站会话”会关闭本站专用窗口并清除该站点的专用资料，需要时可重新登录；它不会清理日常 Edge / Chrome 的浏览记录或账号。

## 验证范围

自动化测试使用隔离临时目录和注入浏览器驱动，检查状态、会话复用、并发、错误处理及本机接口权限。真实账号是否能访问网站，需要用户在原站完成登录后，以“检查连接”的实际结果为准。
