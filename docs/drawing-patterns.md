# 典型电路画法：根据电气结构选布局

本文件配合 [绘图指导](drawing-guide.md) 使用，指导人工绘图、AI 生成候选与自动布局实现。以下是从示例提炼的项目画法，不表示现有排版器已经支持这些能力。

依据为 4,283 个 LTspice ASC 的结构扫描、其中 32 个不同电路的静态精读，以及 TI 原图和 Qucs 源文件研究。扫描用于选样；具体布局判断来自精读，不能声称已理解 4,283 种电路。

## 使用方法

1. 先核对实际引脚身份、模型端口、网标和连接；再识别下面的功能块。一张图可以组合多种画法。
2. 将已确认的主路径、反馈、供电、采样、重复单元写成布局约束；型号相似或几何接近不能作为连接证据。
3. 先放功能块和器件，再预留引脚出口、文字和反馈通道，最后布线；布局失败时保留原图并指出冲突。
4. `G` 表示当前电气吸附栅格。引脚出口可从 1–2G 起步，平行通道可从 2G 起步；这是可调整建议，实际间距由符号、文字和折点边界决定，不能硬套 LTspice 坐标。
5. “上/下/左/右”描述推荐的空间关系，不能覆盖已知端口方向、用户手工布局或电气极性。网标是否替代长线须遵守主指导中的语义与审阅规则。

## 1. RC / RLC 梯形网络

- **识别依据：**沿明确输入到输出追踪串联支路，区分对参考节点的并联支路；不能以电阻、电容的类型直接决定角色。
- **摆放：**串联元件沿主信号轴排列，并联支路向其参考节点展开；多级使用相似节奏，输出留测量空间。
- **走线与文字：**主轴保持连续可读，分支从真实抽头引出；水平元件的位号和值分置空白侧，避免压在支路入口。
- **例外：**桥式、谐振反馈和浮地网络不套梯形模板；不能把所有电容移到地。RLC 是依据已确认串/并联拓扑的推广建议，并非本次精读覆盖了所有 RLC 变体。
- **来源：**[TwoTau 与串联/支路关系](research/2026-09-25-ltspice-drawing-study.md)、[Qucs 级联滤波结构](research/2026-09-25-online-schematic-references.md)。

## 2. 普通反相 / 同相运放

- **识别依据：**核对 In+、In−、OUT 和供电端，沿实际反馈连接确认类型；不要依三角形朝向或屏幕上下判断正负输入。
- **摆放：**输入耦合与输入电阻在信号入口侧，运放居中，输出在出口侧；偏置网络占独立局部区域。
- **走线与文字：**反馈沿运放外侧返回目标输入，供电不横穿反馈；型号文字参与避障，目标端也要保留朝外的引脚出口。
- **例外：**镜像运放的正电源可以位于下方；保持端口身份，不为“统一朝向”交换输入。纯排版不得顺便改变增益或偏置参数。
- **来源：**[UniversalOpAmp2 的端口与窗口](research/2026-09-25-ltspice-drawing-study.md)、[TI AC 耦合反相放大器](research/2026-09-25-online-schematic-references.md)。

## 3. Sallen-Key 与重复有源滤波级

- **识别依据：**确认输入 RC 网络、输出返回滤波节点的支路及运放局部反馈；不能把所有回接都视为同一条负反馈。
- **摆放：**输入串联网络沿主轴接近运放；滤波反馈外圈与运放自身反馈分开；级联时先保留每一级完整结构。
- **走线与文字：**为外圈反馈预留一条通道，参考节点支路向另一侧展开；每级的位号、值和输出网标都要有独立空白。
- **例外：**多级可因端口高度逐级错位，不强制符号中心齐平。反馈电容与对参考点电容不能按“都是 C”相互替换位置或连接。
- **来源：**[TI SBOA226 与 Qucs active_lp.sch](research/2026-09-25-online-schematic-references.md)。

## 4. 跨阻放大器 TIA

- **识别依据：**确认电流输入接入的求和节点，以及输出到该节点的反馈 R/C；不能只因出现光电二极管就猜测极性或偏置。
- **摆放：**传感/电流输入靠近求和节点，运放与输出沿阅读方向排；并联反馈 R/C 分层放在同一外侧区域。
- **走线与文字：**两反馈元件共享两个真实节点，各层文字留在线间空白；供电与去耦可单独成块，沿原网标关联。
- **例外：**输入电流源并不自动等于对地支路；保留传感器偏置、模型与输入参考。布局紧凑不代表已经验证稳定性或噪声性能。
- **来源：**[TI SBOA268B 跨阻放大器](research/2026-09-25-online-schematic-references.md)。

## 5. 多反馈与电流输出电路

- **识别依据：**沿每一条回路追踪其起点、目标引脚和采样节点；显式识别用户指定输出，不把运放尖端自动当成唯一输出。
- **摆放：**不同反馈环分配不同外侧通道；局部增益网络靠近输入端，跨级反馈放在功能块外围，负载保留原支路关系。
- **走线与文字：**平行回路分层，必要时接受更长外围线；如 HP/BP/LP、Iout 等明确功能名保留，避免自动网名淹没它们。
- **例外：**Howland 的负载电流支路不能改到运放输出脚；反馈正负及用途须有连接或文档证据，识别不明时保留原组并说明。
- **来源：**[三运放 opamp 示例](research/2026-09-25-ltspice-drawing-study.md)、[Howland 与 LM741 外围反馈](research/2026-09-25-ltspice-educational-expanded.md)。

## 6. 振荡器 / PLL

- **识别依据：**先确认闭环、选频/滤波网络、稳幅或控制环；振荡器没有外部信号源时，不虚构一个输入作为分层根节点。
- **摆放：**主环形成可顺着阅读的路径，稳幅/偏置在侧边或下方；PLL 前向链与返回链各占通道，Royer 可采用上下分区。
- **走线与文字：**长返回线走外围；Laplace、PULSE 等长字段留单独区域或可追溯摘要，不用挤小字体腾出走线空间。
- **例外：**不要把闭环硬拆成无环链；双管跨耦合的相交线路仍是各自网络。导入已有斜线保留连接，新路由默认正交。
- **来源：**[Wien、PLL、Royer](research/2026-09-25-ltspice-educational-expanded.md)、[astable](research/2026-09-25-ltspice-drawing-study.md)。

## 7. BJT / MOS 差分对、电流镜与互补级

- **识别依据：**根据实际 C/B/E、D/G/S/B 身份及共享节点识别输入对、镜像和偏置；不能仅凭两只同型号器件成对处理。
- **摆放：**差分对保持相向或对称关系，尾支路与公共节点靠近成对器件；镜像和负载另成局部组，级间顺序清晰。
- **走线与文字：**共用连接与两路独立输出分开；镜像后重算每个端口和字段位置，文字放到各自外侧，避免夹在窄缝中。
- **例外：**外观对称不允许交换器件端口、体端或互补型号；不能为了对齐删掉单边补偿、发射极/源极电阻或独立偏置。
- **来源：**[LM741、BandGaps](research/2026-09-25-ltspice-educational-expanded.md)、[Qucs singleOPV.sch](research/2026-09-25-online-schematic-references.md)、[100W](research/2026-09-25-ltspice-drawing-study.md)。

## 8. 开关 / 保护 / 电源切换

- **识别依据：**确认主功率通路、控制端、采样及状态输出；背靠背关系由真实 MOS 端口和连接确定，不能靠图形朝向猜。
- **摆放：**功率路径成连续主轴，驱动与保护控制在旁；双电源采用并列入口，在已存在的汇流点合并阅读路径。
- **MOS 负载例：**先确认低边供电→负载→D→S→地，还是高边源极跟随供电→D→S→负载→地。高边例中 S 到地的电阻可以就是负载；输入放左、MOS 沿主路径、负载放右侧输出区并向下接地，右行主路 D 在左、S 在右，Gate 置于通道外侧。低边例让负载在 MOS 漏极前方；高边 PMOS 则按实际 S 接供电、D 接负载核对。不能因同为 MOS 而互换拓扑。
- **走线与文字：**Gate、UV/OV、Sense、FAULT 各走相应端口通道；相邻 MOS 的文字分别摆放，长激励值避开主轴。
- **例外：**两个输入源不得因汇流外观直接短接；IGBT、DIAC/TRIAC 使用各自端口定义，不能套用 MOS 符号或前缀。
- **来源：**[LTC4365、LTC4412](research/2026-09-25-ltspice-applications-expanded.md)、[IGBT、dimmer](research/2026-09-25-ltspice-educational-expanded.md)。
- **项目内验收例：**[2N7002 / RC 重画对照](artifacts/2026-09-25-protection-redraw/README.md)。当实际连接为串联输入二极管、漏极负载、低边 NMOS 与 Gate 并联 RC 时，可将负载/MOS 排成同列，Gate 充电支路与并联下拉单独展开；不把所有器件沿供电网横排。长 PULSE 文字需要单独留白，输出标注也不能压住 MOS。本例保留全部导线身份，外围返回线因此仍较长，不作为所有保护电路的固定模板。

## 9. LDO

- **识别依据：**核对输入、输出、参考/地、使能及旁路/反馈引脚；器件类型和模型引脚映射须明确。
- **摆放：**输入与输出沿端口方向展开，各自电容放在所属一侧；使能、旁路、调压支路靠近对应引脚。
- **走线与文字：**端口先引出再转向电容或反馈支路；负载与输出标签留在输出区域，不把全部地端拉成穿过器件的大横线。
- **例外：**负压 LDO、浮动参考及可调版本不套正压固定输出模板；旁路电容不能作为普通输出电容移位或改接。
- **来源：**[LT1763 的输入/输出与旁路布局](research/2026-09-25-ltspice-drawing-study.md)。

## 10. Buck / 同步 Buck

- **识别依据：**确认开关节点、输出电感、负载与反馈抽头；外置桥臂、续流器件和电流采样依原电路区分。
- **摆放：**开关节点—电感—输出构成主路径，输出电容和负载形成支路；反馈分压与补偿在控制器附近单独安排。
- **走线与文字：**反馈从真实输出/采样点返回 FB；Sense+ 与 Sense− 保留两条独立路线，位号和值不要压在开关抽头上。
- **例外：**不按最短距离把反馈改接电感前端；原理图的紧凑排版不等于 PCB 高 di/dt 环路已满足要求。
- **来源：**[LT8609](research/2026-09-25-ltspice-drawing-study.md)、[LTC3890](research/2026-09-25-ltspice-applications-expanded.md)、[Qucs Buck](research/2026-09-25-online-schematic-references.md)。

## 11. Boost / Buck-Boost / 充电器

- **识别依据：**从电感、开关抽头、整流/桥臂和反馈确认实际拓扑；充电器另识别 BAT、采样及功率分配支路。
- **摆放：**简单 Boost 可用电感—二极管—输出主轴；四开关结构先摆桥臂与控制器，再按 SW 端口安排电感，允许在下方绕行。
- **走线与文字：**功率与控制各留通道，充电支路单独成区；采样电阻两端各自返回对应采样脚，多行电池等效参数计入边界。
- **例外：**不能强制电感总在上方；BAT 的电容等效支路不能被当作普通去耦搬走，反相/非反相支路不能凭外形合并。
- **来源：**[LT8330、LTC3780、LTC4020](research/2026-09-25-ltspice-applications-expanded.md)。

## 12. 反激 / 变压器 / 磁耦合

- **识别依据：**读取 K 声明、绕组名称、方向与模型说明；先区分线性耦合绕组与受控源构成的磁芯等效模型。
- **摆放：**相关绕组视觉成组，一次控制/开关与二次整流/负载分区；耦合声明及极性标识放在可辨认的空白区域。
- **走线与文字：**绕组间留出位号、值和极性点空间，反馈按实际采样侧返回；多绕组的每条支路保留独立出口。
- **例外：**K 不是电线；不能因“隔离反激”名称擅自拆开输入中共用的仿真地。Chan 等非线性模型不能替换成普通 K 模板。
- **来源：**[Transformer2、NonLinearTransformer、Royer](research/2026-09-25-ltspice-educational-expanded.md)、[LT8306](research/2026-09-25-ltspice-applications-expanded.md)。

## 13. 多相电源

- **识别依据：**核对控制器 PWM/驱动端口、功率级、电感及所属输出，确认重复相位单元和共享母线；器件数量不是相数证据。
- **摆放：**先确定一相的内部关系，再按列/行复制空间节奏；控制器可居中，相位向两侧展开，输出按实际分组汇流。
- **走线与文字：**母线、PWM、采样分别留通道；各相标号完整显示，采样从指定输出点返回，不从视觉最近的母线点猜接。
- **例外：**重复只复用空间约束，不复制或重编号电气关系；不能把 OUT0/OUT1 合成同一输出，也不能把所有相拉成一条长链。
- **来源：**[LTC3888 的 8 相与双输出组织](research/2026-09-25-ltspice-applications-expanded.md)。

## 14. 多输出与不对称双通道

- **识别依据：**按实际输出网和反馈引脚分组，逐支路核对器件；不能因左右近似对称就判定两路电气结构相同。
- **摆放：**共享控制器/输入在中心或共同一侧，输出支路向不同方向展开；两路可保持节奏，但按实际复杂度分配面积。
- **走线与文字：**每路输出、反馈和采样各自可追踪；串联耦合电容、整流支路和不同极性的反馈要留独立位置。
- **例外：**LT1945 的两翼并不完全相同；禁止为了镜像美观删除单边器件、交换 NFB/FB，或强迫所有输出移到右侧。
- **来源：**[LT1945、LTC3890](research/2026-09-25-ltspice-applications-expanded.md)。

## 15. 全差分驱动 / ADC 信号链

- **识别依据：**读取 IN+/IN−、OUT+/OUT−、VOCM 和 ADC 端口；区分单个全差分放大器与两个普通运放组成的转换器。
- **摆放：**输入—驱动—滤波—ADC 按功能成块，差分两路保留配对关系；供电、共模、数字配置另占局部区域。
- **走线与文字：**上下反馈各有通道，正负网名保留在对应线上；交叉处不自动连接，功能说明框和长配置值均参与避障。
- **例外：**旋转/镜像不改变正负网络身份；差分成对不意味着原理图强制等长，也不能把不同数字输出或控制脚视为信号对。
- **来源：**[AD4080、LTC6363、LT6014](research/2026-09-25-ltspice-applications-expanded.md)。

## 16. 对照块、测量支路与同页波形

- **识别依据：**依据标题、输出名、仿真配置或明确连接识别方案对照与测量用途；相似外观不等于重复冗余。
- **摆放：**对照电路整块对齐基准，块内按各自结构排布；测量支路与模型说明留独立区域，波形图框占独立画布空间。
- **走线与文字：**共享激励只保留原有连接；A/B 等对照输出名、公式和单位完整保留。图框扩大时避开电路，不通过挪电气节点强行腾空。
- **例外：**测功率的行为源和采样保持的不同触发路径不得删并；说明框不是导线，图表曲线不是电气网络，禁止参与普通连接分层。
- **来源：**[BandGaps、SampleAndHold、dimmer](research/2026-09-25-ltspice-educational-expanded.md)、[Qucs 同页波形](research/2026-09-25-online-schematic-references.md)。

## 应用后的检查

每次选用上述画法，至少说明“识别了哪些功能块、预留了哪些反馈/采样通道、哪些位置保留原样及原因”。只改布局时，应验证端口连接、模型、参数、网标和测量绑定不变；截图好看不能代替电气等价检查。

未知器件、冲突端口或不能确认的功能块先保留原关系，仅做有依据的局部整理；不得猜测补线。验收按 [绘图指导](drawing-guide.md) 执行，并记录采用的典型画法与未解决冲突。
